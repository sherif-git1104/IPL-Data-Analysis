# IPL Data Analysis

Analysis of Indian Premier League match and delivery data using Python and Power BI.

## Project files

- `IPL_Analysis.ipynb`: Python data analysis notebook.
- `matches.csv`: Match-level IPL dataset.
- `deliveries.csv`: Ball-by-ball IPL dataset.
- `IPL DASHBOARD ANALAYSIS.pbix`: Power BI dashboard.

## Setup

Create a virtual environment and install the dependencies:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Open `IPL_Analysis.ipynb` in Jupyter or VS Code and run the cells from the project directory so the CSV files resolve correctly.
